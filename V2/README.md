# Projeto HTML — Márcia Locutora

> **⛔ DIRETIVA DE ESCOPO:** todo trabalho neste projeto deve ficar restrito à pasta `V2/`.
> **Não alterar nenhum arquivo fora de `V2/`** (raiz do repositório, `Images/`, `CNAME`, etc.) —
> o que está fora está **em produção**. Leitura fora da `V2/` é permitida; escrita, exclusão ou
> commit de arquivos fora dela exige autorização prévia do usuário. Detalhes: `docs/REFERENCIA-ANALISE-V2.md`.

Esqueleto completo de um novo site, com navegação funcional, estrutura semântica e textos iniciais orientados a acessibilidade, SEO e descoberta por mecanismos de busca/IA.

## Importante

Este pacote é deliberadamente um esqueleto: não há design visual, logo final, imagens, áudios reais, dados de contato ou textos finais inventados.

Antes da publicação:
1. Substituir placeholders por informações reais e autorizadas.
2. Inserir áudios e vídeos reais com nomes acessíveis e transcrições/descrições.
3. Conectar o formulário a um serviço de envio.
4. Configurar HTTPS, sitemap e Search Console.
5. Revisar URLs antigas e criar redirects 301 quando necessário.
6. Adicionar dados estruturados Schema.org adequados a cada página.
7. Validar HTML e acessibilidade.
8. Criar conteúdo editorial original para cada artigo.

O projeto usa links absolutos a partir da raiz (`/`). Portanto, deve ser servido na raiz de um domínio ou em um servidor configurado para isso.
